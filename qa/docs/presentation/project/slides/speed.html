Вторая проблема — скорость. Когда сайт заработал без VPN, оказалось, что первая загрузка идёт долго: канал до домашнего компьютера узкий, а сайт весил 1,6 мегабайта. Приложение APK вообще весило 54 мегабайта — через туннель его было бы не скачать. Что я сделал. Все файлы сайта сжимаются заранее, при сборке, алгоритмом brotli — сайт стал весить 0,5 мегабайта. Включил долгий кэш: при повторном открытии файлы не скачиваются вовсе. Разбил сайт на части: каждая страница загружает только свой код. Вместо фотографий деталей — векторные рисунки по 1,4–5,3 килобайта. APK собрал отдельными файлами под разные процессоры: вместо 54 мегабайт — 19. Результат: сайт на телефоне без VPN открывается за 0,3–0,8 секунды. Это важно и для судов: по техническому заданию связь может быть всего 128 килобит в секунду.
